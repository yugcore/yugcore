# YUG

**Graphics · Game Engines · Systems · Programming Languages**

I build game engines from the ground up — working across rendering, GPU architecture, asset pipelines, scripting runtimes, gameplay systems, and developer tooling.

I’m interested in the layers underneath the abstractions: how engines work, how software reaches the hardware, and how those systems can be designed from scratch.

## Technical Focus

**Graphics & Rendering**
Modern rendering pipelines, GPU-driven systems, shaders, lighting, PBR, post-processing, and Direct3D 12.

**Game Engine Architecture**
Rendering architecture, asset systems, scene systems, gameplay frameworks, serialization, tooling, and editor technology.

**Programming Languages**
Interpreters, bytecode virtual machines, compilers, runtime architecture, and native bindings.

**Systems Programming**
C++, Rust, low-level architecture, performance, memory, and hardware-oriented software.

## Philosophy

> **Don't just use the abstraction. Build the layer underneath it.**

I like working where software meets hardware — where a renderer becomes a GPU workload, a programming language becomes a runtime, and an engine becomes a collection of systems working together.
